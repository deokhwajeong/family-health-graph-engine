⚙️ iOS Shortcuts Setup

Configure real-time health data sync

API Endpoint

🚶 Steps

POST /api/health/steps

Parameters:

  • person_name: Sei or Deokhwa
  • steps: Number of steps
  • timestamp: ISO 8601 format

❤️ Heart Rate

POST /api/health/heart-rate

Parameters:

  • person_name: Sei or Deokhwa
  • bpm: Beats per minute
  • timestamp: ISO 8601 format

😴 Sleep

POST /api/health/sleep

Parameters:

  • person_name: Sei or Deokhwa
  • start_time: ISO 8601 format
  • end_time: ISO 8601 format
  • quality: good, fair, or poor

🔥 Calories

POST /api/health/calories

Parameters:

  • person_name: Sei or Deokhwa
  • calories: Amount
  • type: active or dietary
  • timestamp: ISO 8601 format

📱 Setup Instructions

  1. Open the Shortcuts app on your iPhone
  2. Tap the + button to create a new shortcut
  3. Add "Get Health Sample" action to retrieve data from Health app
  4. Add "Get Contents of URL" action
  5. Paste the endpoint URL from above
  6. Set Method to POST
  7. Add form data with the required parameters
  8. Save and test your shortcut
